## Fix note (post-review)

Review flagged `src/routes/challenges/grammar/mubtada-khabar/index.tsx:23` — the question text
read `المحمدٌ في الفصلِ`, illegally combining أل with تنوين on the same word (the exact
impossible combination that `definiteness-tanwin` teaches as a rule), and محمد is a proper noun
that doesn't take أل in standard usage anyway. Presented as a plain example (not an
error-spotting question), this would have taught malformed Arabic as correct.

Fixed by changing the question text from `المحمدٌ في الفصلِ` to `محمدٌ في الفصلِ` — dropping the
أل since محمد is already definite as a proper noun. The options and the `a` explanation didn't
reference أل anywhere, so no other text needed to change; the question reads coherently as a
مبتدأ (محمدٌ, proper noun, رفع) + خبر (في الفصلِ, شبه جملة جار ومجرور) example.

from `<Link to="/challenges/grammar">` across the new files because the grammar hub route
